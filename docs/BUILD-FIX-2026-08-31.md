# abattery3D — corrección de arranque

## Incidencia
La APK compilaba correctamente, pero Android no podía instanciar la Activity declarada en el Manifest.

Error observado:
`ClassNotFoundException: Didn't find class "com.stylo.abattery3d.MainActivity"`

## Causa
`MainActivity.kt` pertenecía al paquete `com.stylo.batterymonitor`, mientras la aplicación utiliza el namespace `com.stylo.abattery3d`.

## Corrección
Se ha cambiado el package de `MainActivity` a `com.stylo.abattery3d`, manteniendo el resto de componentes en sus paquetes funcionales.

Commit de la corrección:
`8fe848df4ad594c6f8ab449c3ca6ef5db6e15759`

## Verificación
La siguiente ejecución de GitHub Actions debe validar que `com.stylo.abattery3d.MainActivity` está presente en el DEX y que la APK puede arrancar.
